# CORE_MASTER_THESIS

This Python script generates and inserts synthetic data into the `rez` table in the `CORE_MASTER_THESIS` PostgreSQL database.

---

##  Requirements

- Python 3.8+
- PostgreSQL server running locally or remotely
- Required Python packages:
  - `psycopg2-binary`
  - `python-dotenv`
